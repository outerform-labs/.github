# TRACK A — COMPUTATIONAL INVENTION

## A1 — Mechanism Forge

### Vision

A machine is given a library of physical, biological, computational, and engineering mechanisms and deliberately searches for unusual combinations that produce useful capabilities.

Not:

> "Generate product ideas."

But:

> **"What becomes possible if these mechanisms are composed?"**

Example output might be:

- use a thermal phase transition as memory;
- use structural vibration as a communication channel;
- use biological chemotaxis principles for robot navigation;
- combine metamaterial behavior with distributed sensing to create self-localizing structures.

### Why this is interesting

It treats invention as **mechanism composition**, not text generation.

### Sci-fi flavor

A machine that can look at the laws of reality and ask:

> "What weird thing can I build from these?"

---

## A2 — Analogy Engine

### Vision

A system searches for deep structural analogies between unrelated technical fields and proposes transferable solutions.

Examples:

- immune systems ↔ cyber defense;
- ant colonies ↔ distributed manufacturing;
- neural plasticity ↔ adaptive control;
- fluid networks ↔ computation;
- developmental biology ↔ self-assembling robots.

The system is not searching for similar words.

It is searching for:

> **the same causal pattern expressed in different domains.**

### Why this is interesting

Many inventions emerge when someone realizes:

> "This problem in field X is secretly the same kind of problem as something solved in field Y."

---

## A3 — Impossible-Machine Compiler

### Vision

A human gives the system a science-fiction capability:

> "Build me matter that changes function."

> "Give humans a new sense."

> "Create a factory that grows."

The system recursively converts the capability into:

**required functions → physical constraints → candidate mechanisms → unresolved assumptions → testable experiments.**

Its job is not to say:

> "Impossible."

Its job is to ask:

> **"What would have to be true?"**

### Why this is interesting

This could become a direct bridge between wild imagination and engineering.

---

## A4 — Invention Archaeologist

### Vision

A system is placed historically *before* a famous invention existed.

It receives only knowledge available at the time.

Its task:

> rediscover the conceptual leap.

Examples could include:
- transistor;
- radar;
- jet engine;
- catalytic cracking;
- laser;
- MRI;
- internet routing;
- lithium-ion battery architectures.

### Why this is interesting

This creates a measurable test for machine inventiveness.

If a system cannot reconstruct known historical leaps from precursor knowledge, claims that it can invent genuinely new technologies are weak.

### Bigger possibility

The benchmark itself could become infrastructure for evaluating future machine inventors.

---

## A5 — Reality Composer

### Vision

Instead of starting from a desired product, the system starts from a set of physical effects and asks:

> **What useful capability emerges if these effects are orchestrated together in time and space?**

It could search:
- mechanical resonance;
- magnetism;
- optics;
- phase change;
- fluid flow;
- acoustics;
- electrochemistry;
- biological sensing.

The output is not just geometry.

It is a **behavioral machine concept**.

### Sci-fi flavor

A "composer" for physical phenomena.

# TRACK B — COGNITIVE EXOCORTEX

## B1 — Artificial Intuition Layer

### Vision

A system continuously converts complex data into a subtle sensory channel that a human learns to interpret subconsciously.

Examples:

- system risk becomes haptic pressure;
- machine health becomes spatial audio;
- uncertainty becomes a tactile texture;
- network anomalies become a directional sense;
- probability becomes a continuously felt signal.

The long-term goal is not to read numbers.

It is:

> **feel the state of a complex system.**

### Why this is interesting

It could create a genuinely new human capability without invasive neurotechnology.

---

## B2 — Predictive Memory

### Vision

An external memory system retrieves useful information *before* the person consciously asks for it.

Not:

> "Search my notes."

But:

> **"Surface the right memory at the moment it becomes relevant."**

The system models:
- current context;
- goals;
- previous knowledge;
- likely uncertainty;
- future task demands.

### Sci-fi flavor

A memory that behaves less like a database and more like an extra cognitive lobe.

---

## B3 — Parallel Mind

### Vision

A persistent AI process runs in parallel with the human throughout the day.

It does not wait for prompts.

It:
- tracks unresolved questions;
- explores alternate approaches;
- notices contradictions;
- simulates future decisions;
- prepares explanations;
- returns only when it has something important.

The human and AI therefore reason **concurrently** rather than sequentially.

### Why this is interesting

Today's assistants are mostly request/response systems.

A true exocortex may need continuous asynchronous cognition.

---

## B4 — Cognitive Telemetry

### Vision

A system estimates the human's current cognitive state:

- confusion;
- certainty;
- overload;
- forgetting;
- attention;
- conceptual gaps;
- hesitation.

Then it adapts the information environment in real time.

The person does not need to explicitly say:

> "I don't understand."

The system notices first.

### Bigger vision

Computing interfaces that respond to the **state of the mind**, not just keyboard input.

---

## B5 — Skill Implant Without Implant

### Vision

A wearable or environmental system augments a difficult human task so tightly that the machine's assistance becomes learned intuition.

Example domains:
- navigation;
- spatial awareness;
- machine diagnosis;
- music;
- physical coordination;
- engineering inspection.

Over time, the human becomes able to perform tasks they could not previously perform.

### Core question

> Can machine assistance become a learned cognitive/perceptual capability rather than permanent dependence on explicit instructions?

# TRACK C — PROGRAMMABLE MATTER / RECONFIGURABLE PHYSICAL SYSTEMS

## C1 — Universal Morphing Cell

### Vision

A small physical unit can change several useful properties:

- shape;
- stiffness;
- orientation;
- connectivity;
- sensing;
- force transmission.

Many cells combine into larger structures.

The goal is to find a **physical primitive** analogous to a transistor:

> simple individually, transformative when massively composed.

### Bigger vision

Machines made from one programmable structural alphabet instead of hundreds of specialized parts.

---

## C2 — Shape-Shifting Tool

### Vision

One physical object can become multiple functional tools by reconfiguring its geometry and mechanical properties.

Examples:

- gripper;
- wrench;
- support structure;
- crawler;
- manipulator;
- antenna;
- brace.

Not interchangeable attachments.

The **same matter** changes role.

### Sci-fi flavor

A crude first ancestor of a morphing multi-tool.

---

## C3 — Self-Rebuilding Robot

### Vision

A modular robot detects that its current body is poorly suited to a task and physically rebuilds itself from available modules.

Examples:

- wide stable body → narrow crawler;
- crawler → manipulator;
- manipulator → bridge;
- damaged machine → smaller functional machine.

The key capability is:

> **the robot reasons about morphology as part of planning.**

---

## C4 — Physical Function Compiler

### Vision

A user specifies:

> "I need a structure that bends here, locks there, conducts here, stays soft there, and changes shape under this condition."

Software converts this into:

- local material choices;
- unit configuration;
- geometry;
- control logic.

The output is not software.

It is **compiled physical behavior**.

### Bigger vision

A programming language for matter.

---

## C5 — Adaptive Architecture

### Vision

A physical structure changes itself continuously in response to:
- load;
- damage;
- weather;
- occupancy;
- mission;
- energy availability.

Instead of a building, vehicle, or machine being designed for a fixed operating envelope, the structure itself changes its properties.

### Sci-fi flavor

Machines and environments whose bodies behave more like living tissue than inert hardware.

# CROSS-TRACK HYBRIDS

The most interesting inventions may live between tracks.

## X1 — Inventor Exocortex

Combine:

**Mechanism Forge + Cognitive Exocortex**

A human inventor thinks with a persistent machine that:
- searches analogies;
- decomposes wild ideas;
- proposes mechanisms;
- challenges assumptions;
- remembers failed concepts;
- suggests experiments.

The target is not "AI that invents alone."

It is:

> **a human-machine invention organism.**

---

## X2 — Matter Discovery Engine

Combine:

**Computational Invention + Programmable Matter**

The machine searches for reconfigurable physical primitives and proposes candidate mechanisms, architectures, and experiments.

Instead of manually choosing one smart material or modular robot concept, the system searches the space of **physical reconfigurability** itself.

---

## X3 — Cognitive Material Interface

Combine:

**Cognitive Exocortex + Programmable Matter**

A physical interface changes shape, texture, stiffness, or spatial configuration to represent information to a human.

Instead of screens:

> **information becomes physical form.**

The interface could eventually become a new cognitive channel.

---

## X4 — Self-Inventing Machine

Combine all three tracks.

A machine:
1. recognizes a capability it lacks;
2. searches for a new mechanism;
3. designs a physical modification;
4. changes or rebuilds part of itself;
5. tests the new capability;
6. keeps or rejects the modification.

This is far beyond current practical scope, but it is a powerful North Star.

It represents:

> **a machine capable of inventing new parts of itself.**

# Strongest Candidate Concepts for Reality Check

The following concepts appear especially rich because they open large technical trees and feel distinctly Outerform:

## 1. Impossible-Machine Compiler

Why:
- directly operationalizes the lab philosophy;
- bridges sci-fi imagination and engineering;
- can evolve toward machine invention;
- immediately useful to every future Outerform project.

## 2. Artificial Intuition Layer

Why:
- creates a genuinely new human capability;
- non-invasive path exists;
- connects AI, cognition, sensing, human augmentation, and interface design.

## 3. Universal Morphing Cell

Why:
- strongly physical;
- has the "technology from the future" feeling;
- could unlock many reconfigurable machines if a good primitive exists.

## 4. Inventor Exocortex

Why:
- combines human creativity with machine cross-domain search;
- potentially increases Outerform's own rate of invention;
- could become a long-term personal cognitive system.

## 5. Self-Rebuilding Robot

Why:
- visually and technically impressive;
- combines autonomy, morphology, planning, robotics, resilience, and programmable matter;
- contains multiple attackable subproblems.

## 6. Physical Function Compiler

Why:
- turns desired physical behavior into automatically synthesized matter/structure;
- connects computation directly to physical form;
- could become foundational infrastructure for reconfigurable machines.
